# Distribution Visualisation Exercises

Two small Plotly exercises for exploring distributions.

## Scripts

- `c109/code.py` — plots the distribution of the `Avg Rating` column in `data.csv`.
- `c109/sampleing.py` — plots the distribution of the `temp` column in `newdata.csv`.

## Requirements

```bash
pip install pandas plotly
```

## Run

Run each script from the `c109` directory:

```bash
python code.py
python sampleing.py
```

The sampling script currently calculates the population mean but does not perform repeated random sampling despite its filename. The original scripts are retained as learning exercises.
